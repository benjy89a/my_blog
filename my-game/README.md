## 📝 업데이트 기록

처음 만든 뒤 직접 플레이해 보면서 아래 순서대로 고쳤어요.

### v1. 처음 버전
- 세로줄 3개 보드, 주사위 굴리기와 리롤(1회), 시너지, 파괴, 실드, 결과 모달
- 처음에 정한 규칙
  - 시너지는 같은 숫자끼리만 배수 적용
  - 실드 확률 1/6
  - 상대 보드에 놓은 실드 점수는 보드 주인 것
  - 이긴 줄 수가 같으면 총점으로 판정

### v2. 가로줄 + 파괴 규칙 강화
- 줄 방향을 **세로 → 가로**로 변경
- 파괴할 때 **내 주사위도 함께 사라지게** 변경 (실드는 남음)
- 시너지는 **바로 옆에 붙어 있을 때만** 적용 (`1 3 1`은 시너지 없음)

### v3. 칸 개념 추가
- 칸을 직접 고르는 대신 **줄만 고르면 안쪽부터 차례로 쌓이게** 변경
- 파괴는 **상대 줄의 맨 앞 주사위만** 가능
- 파괴 뒤 남은 주사위는 **안쪽으로 당겨짐**

### v4. 클릭으로 부수기
- 부술 수 있는 상대 주사위에 **💥 표시 + 깜빡임**
- **💥 주사위를 클릭**해서 바로 부수기 (내 줄을 눌러도 자동으로 부서짐)

### v5. 종료 조건 버그 수정
- 🐞 한쪽 보드만 꽉 차도 게임이 끝나던 버그를 수정 → **양쪽이 모두 꽉 차야 종료**
- 테스트 모드의 선택값을 브라우저가 기억하지 않게 수정

### v6. 실드 공격 규칙 정리
- 실드는 상대의 **완전히 텅 빈 줄에만** 놓을 수 있음
- **각자 첫 턴**에는 상대 보드에 놓을 수 없음

### v7. 꽉 찬 보드도 공격 기회
- 보드가 꽉 찬 쪽도 **주사위를 굴려서** 실드가 나오면 공격 가능
- 놓을 곳이 없으면 **⏭ 턴 넘기기** (리롤이 없으면 자동으로 넘김)

### v8. 문서
- 규칙을 정리한 [`PRD.md`](PRD.md) 추가
- 이 README 추가

## 🔍 회고: 처음부터 자세한 가이드라인이 있었다면

### 무엇이 있었나
게임은 처음 요청 한 번으로 만들어졌지만, 실제로 해보면서 **규칙을 바꾸는 수정이 6번(v2~v7)** 이어졌어요. 수정이 잦았던 이유는 코드를 잘못 짜서가 아니었어요. **처음 요청에 머릿속 게임의 모습이 다 적혀 있지 않았기** 때문이에요.

| 처음 요청 | 실제로 원했던 것 | 바뀐 버전 |
|---|---|---|
| "세로 3줄" | 가로줄 | v2 |
| "같은 숫자가 2개면 ×2" | **붙어 있는** 같은 숫자만 | v2 |
| "한 줄을 선택해 빈칸에 배치" | 안쪽부터 **순서대로 쌓기** | v3 |
| "동일한 줄에 같은 숫자가 있으면 파괴" | 상대 줄의 **맨 앞만** 파괴 + 내 주사위도 사라짐 | v2, v3 |
| "한쪽 보드 9칸이 차면 즉시 종료" | **양쪽 모두** 차야 종료 | v5 |
| "상대방 진영의 빈칸에도 배치" | **텅 빈 줄에만**, 첫 턴은 금지 | v6, v7 |

특히 v5의 "치명적인 버그"는 사실 **처음 요청에 적힌 대로 동작한 결과**였어요. 글로 쓴 규칙과 머릿속 규칙이 달랐던 거예요. 규칙 하나를 바꾸면 다른 규칙도 따라 바뀌는 일도 많았어요. 예를 들어 "붙어 있어야 시너지"로 바뀌자 "칸의 위치"가 중요해졌고, 그래서 "쌓는 순서"와 "파괴 뒤 당기기"까지 정해야 했어요.

### 배운 점
1. **"같은 줄", "빈칸", "끝나면" 같은 말은 여러 뜻으로 읽혀요.** 규칙마다 **예시 하나**(`1 3 1`은 몇 점?)를 붙이면 오해가 거의 사라져요.
2. **"이럴 땐 어떻게 되지?"를 미리 적어야 해요.** 보드가 꽉 차면? 실드끼리 만나면? 첫 턴에는? 이런 예외 상황에서 수정이 가장 많이 나왔어요.
3. **화면보다 규칙을 먼저 확정하는 게 좋아요.** 규칙이 바뀌면 화면(줄 방향, 클릭할 곳, 안내 문구)도 같이 바뀌어요.
4. **주고받은 질문이 큰 도움이 됐어요.** 애매한 부분을 코드 짜기 전에 물어본 덕분에, 수정은 많았어도 방향이 엇나간 적은 없었어요.

### 다음에는 이렇게
게임을 만들기 전에 아래 항목을 먼저 채워서 요청하면, 수정 횟수를 크게 줄일 수 있어요.

- [ ] **보드 모양**: 줄의 방향, 칸 수, 어느 쪽이 "앞"인지
- [ ] **놓는 방법**: 칸을 고르는지, 줄만 고르고 자동으로 쌓이는지
- [ ] **점수**: 계산식과 예시 3개 이상 (특히 헷갈리는 경우)
- [ ] **상호작용**: 파괴, 방해 같은 규칙이 일어나는 **정확한 조건**과 일어난 **뒤의 상태**
- [ ] **예외 상황**: 첫 턴, 보드가 꽉 찼을 때, 놓을 곳이 없을 때, 동점일 때
- [ ] **종료와 승패**: 언제 끝나고, 어떻게 이기는지
- [ ] **조작**: 무엇을 눌러서 무엇을 하는지

이번에 만든 [`PRD.md`](PRD.md)가 바로 이런 가이드라인의 완성본이에요. 다음 게임은 PRD를 먼저 쓰고 시작해 볼 생각이에요.

## 📖 게임 규칙

### 기본
- 나와 AI는 각각 **가로줄 3개 × 3칸 = 9칸** 보드를 가집니다.
- 내 턴에 주사위(1~6)를 굴리고 **줄을 고르면**, 주사위가 **가운데 쪽(안쪽)부터 차례로** 쌓입니다.
- 리롤은 **게임당 1번**만 쓸 수 있어요.
- 항상 내가 먼저 시작해요.

### 🔗 시너지
같은 숫자가 **바로 옆에 붙어 있을 때만** 점수가 올라가요. 계산법은 `(같은 숫자들의 합) × 개수`예요.

| 줄 | 점수 |
|---|---|
| `1 1 2` | (1+1)×2 + 2 = **6** |
| `1 3 1` | 붙어 있지 않아서 1+3+1 = **5** |
| `5 5 5` | (5+5+5)×3 = **45** |

### 💥 파괴 (알까기)
- 같은 번호 상대 줄의 **맨 앞(가운데와 가장 가까운) 주사위**가 내 숫자와 같으면 부술 수 있어요.
- 맨 앞이 아닌 주사위는 막혀 있어서 안전해요.
- 부술 수 있는 주사위에는 💥가 깜빡여요. **그 주사위를 직접 누르거나** 내 줄을 누르면 부서져요.
- 부수면 **내 주사위도 함께 사라지고**, 남은 주사위는 안쪽으로 당겨져요.

### 🛡 실드 주사위
- 굴릴 때 **1/6 확률**로 실드 주사위가 나와요.
- 실드는 **절대 부서지지 않아요.** 실드로 상대를 부수면 내 실드는 그대로 남아요.
- 상대 보드의 **완전히 텅 빈 줄**에도 놓을 수 있어요. 그 칸 점수는 보드 주인 것이에요.
- 단, **자기 첫 턴**에는 상대 보드에 놓을 수 없어요.

### 🏁 게임 종료
- **양쪽 보드가 모두 꽉 차면** 게임이 끝나요.
- 보드가 먼저 꽉 찬 쪽도 주사위는 굴려요. 실드가 나오면 공격할 수 있고, 놓을 곳이 없으면 턴을 넘겨요.
- 3줄 중 **2줄 이상 이긴 쪽이 승리**해요. 그런 쪽이 없으면 총점으로 판정하고, 총점도 같으면 무승부예요.
