# PRD: 나만의 투두리스트

## 1. 서비스 목적

- **누구의**: 나 (개인 생산성 향상이 목표인 사용자)
- **어떤 문제를**: TickTick 같은 기존 투두리스트 앱은 유료이고, 쓰지 않는 기능이 많아 복잡하다.
- **어떻게 해결하는가**: 내가 실제로 쓰는 기능(할 일 관리, 목록 나누기)만 담은 **무료이고 가벼운 웹 투두리스트**를 직접 만든다.

## 2. 선택한 프레임워크

- **React** (Vite로 프로젝트 생성 예정)
- **선택 근거**: 우선 기준인 **인력·자료**와 **장기 유지보수**에서 가장 앞선다. 학습 부담은 크지만, 범용성이 높아 나중에 활용도가 높다. Vue와 Svelte는 자료와 확장성 면에서 기각했다. 자세한 내용은 `선택-근거.md`를 참고한다.

## 3. 핵심 화면

### 메인 화면 (한 화면 구조)

```
┌──────────┬─────────────────────┐
│ 📁 목록   │  공부                │
│  공부  ◀ │  ☐ 수학 숙제          │
│  업무     │  ☐ 영어 단어          │
│  개인     │  ☑ 독서 30분          │
│ + 새 목록 │  [+ 할 일 추가]       │
└──────────┴─────────────────────┘
```

| 영역 | 역할 |
|---|---|
| 왼쪽: 목록 사이드바 | 목록(공부, 업무, 개인 등)을 보여 준다. 선택한 목록을 표시하고, 새 목록을 추가한다. |
| 오른쪽: 할 일 영역 | 선택한 목록의 할 일을 보여 준다. 할 일 추가, 완료 체크, 삭제를 한다. |

### 이동 흐름
1. 앱을 열면 첫 번째 목록이 선택된 상태로 메인 화면이 보인다.
2. 왼쪽에서 목록을 클릭하면, 오른쪽에 그 목록의 할 일이 나타난다. (페이지 이동 없이 같은 화면에서 바뀜)
3. 오른쪽에서 할 일을 추가, 체크, 삭제하면 바로 화면에 반영된다.

## 4. 요구사항

| # | 사용자가 할 수 있어야 하는 일 | 확인할 조건 |
|---|---|---|
| R1 | 목록 전체를 볼 수 있다 | 앱을 열면 왼쪽에 목업 목록(공부, 업무, 개인)이 보인다 |
| R2 | 목록을 선택할 수 있다 | 목록을 클릭하면 선택 표시가 되고, 오른쪽에 그 목록의 할 일만 보인다 |
| R3 | 새 목록을 추가할 수 있다 | 이름을 입력하고 추가하면 왼쪽 목록에 새 항목이 생긴다. 빈 이름은 추가되지 않는다 |
| R4 | 할 일을 추가할 수 있다 | 이름을 입력하고 추가하면 현재 목록에 새 할 일이 생긴다. 빈 입력은 추가되지 않는다 |
| R5 | 할 일을 완료 체크할 수 있다 | 체크박스를 누르면 완료 표시(취소선)가 되고 목록 맨 아래로 내려간다. 다시 누르면 해제되어 미완료 할 일들 쪽으로 돌아간다 |
| R6 | 할 일을 삭제할 수 있다 | 삭제 버튼을 누르면 그 할 일이 목록에서 사라진다 |
| R7 | 할 일 이름을 고칠 수 있다 | 할 일을 더블클릭하면 입력 칸으로 바뀐다. Enter를 누르면 저장되고, Esc를 누르면 취소된다. 빈 이름으로는 저장되지 않는다 |
| R8 | 빈 목록에서 안내를 볼 수 있다 | 할 일이 하나도 없는 목록을 선택하면 "할 일이 없습니다" 안내가 보인다 |

### 배포
- **GitHub Pages**에 올린다. (현재 `my_blog` GitHub 저장소 사용)

## 5. 이번 구현 범위

### ✅ 목업 데이터로 구현할 것 (오늘 완성)
- 메인 화면 (왼쪽 목록 + 오른쪽 할 일)
- 목업 데이터: 미리 넣어 둔 목록 3개(공부, 업무, 개인)와 각 목록의 예시 할 일
- 동작: 목록 선택, 새 목록 추가, 할 일 추가, 완료 체크, 삭제, 이름 수정, 빈 목록 안내 (R1~R8)
- 데이터는 화면이 켜져 있는 동안만 유지된다. **새로고침하면 처음 목업 상태로 돌아간다.**

### ⏸️ 나중에 백엔드가 필요한 것
| 기능 | 이유 |
|---|---|
| 데이터 저장 (새로고침 후에도 유지) | 데이터를 보관할 저장소(데이터베이스)가 필요하다 |
| 알림 받기 (할 일 시간 알림) | 브라우저를 닫아도 알림을 보내려면 서버(푸시 알림)가 필요하다. 알림 시간 설정 방식도 **[미정]** |
| 여러 기기 동기화 | 휴대폰과 PC에서 같은 데이터를 보려면 서버와 로그인이 필요하다 |

### ❌ 이번에 하지 않는 것
- 목록 이름 바꾸기, 목록 삭제 (나중에 추가)
- 태그, 우선순위, 캘린더 보기, 반복 일정, 하위 할 일, 뽀모도로, 습관 체크 (불필요한 기능을 없애는 것이 목적)
